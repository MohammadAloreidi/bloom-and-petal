# Bloom & Petal

A responsive and interactive flower shop website created using Figma Make, React, TypeScript, and Vite.

## Features

- Responsive e-commerce layout
- Product categories
- Product details modal
- Shopping cart interactions
- Wishlist functionality
- Modern flower shop interface

## Technologies

- Figma Make
- React
- TypeScript
- Vite
- Git
- GitHub
- GitHub Pages

## Live Demo

https://mohammadaloreidi.github.io/bloom-and-petal/

## What I Learned

- Exporting and running a Figma Make project locally
- Working with React and Vite project structure
- Building a production version
- Publishing a Vite website using GitHub Actions and GitHub Pages
